{# Snippet: image-upload.html Path: templates/v2/components/image-upload.html Renders a c-image-upload — an image field that is either an uploaded file or a linked URL (CKAN uploader contract: url / upload / clear fields). With JS (image-upload.js) it shows one state at a time: blank — Upload + Link buttons attached — thumbnail (+ the chosen file's name) + Remove web — URL input + × reset Remove and × empty the URL and set the clear field to 'true'; choosing a file resets it. Choosing a file or entering a URL dispatches a bubbling `image-upload:change` event. Without JS the URL input and the native file input render. With uploads disabled only the URL input renders.

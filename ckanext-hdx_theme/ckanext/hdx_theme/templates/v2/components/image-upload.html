{# Snippet: image-upload.html Path: templates/v2/components/image-upload.html Renders a c-image-upload — an image field that is either an uploaded file or a linked URL (CKAN uploader contract: url / upload / clear fields). With JS (image-upload.js) it shows one state at a time: blank — Upload + Link buttons attached — thumbnail (+ the chosen file's name) + Remove web — URL input + × reset Remove and × empty the URL and set the clear field to 'true'; choosing a file resets it. Choosing a file or entering a URL dispatches a bubbling `image-upload:change` event. Without JS the URL input and the native file input render. With uploads disabled only the URL input renders. link_enabled=False drops Link, the web state and ×; the value posts from a hidden field_url input. remove_enabled=False shows Upload instead of Remove in the attached state, so a new file replaces the stored one. With both off no clear field renders. preview='l' puts a full-width preview box above the label: the image at its own height, or an empty box (no image, broken image). max_bytes / image_width check a chosen file, which must also decode as an image; a failing file is dropped and check_message shows in the error element and is announced. Fields inserted later initialise on a bubbling `config-item:add` event from their container (components/config-item.js).

{# Snippet: resource-card.html Path: templates/v2/components/resource-card.html Renders a .c-resource-card component for a single dataset resource. Parameters ────────────────────────────────────────────────────── title {string} Resource display name. default: '' title_href {string} URL of the resource detail page. default: '#' format_text {string} Format string shown next to icon (e.g. 'GEOJSON'). Rendered uppercase. Pass '' to omit. default: '' format_category {string} Icon category: 'neutral' | 'geo' | 'tabular' | 'document' | 'web'. Drives the file-type-icon colour and icon. Use h.hdx_format_to_icon_category() to derive this from res.format. default: 'neutral' description {string} Full description text. Clamped by default; expanded when user clicks "Show more". Pass '' to omit. The "Show more" button is rendered whenever description is present; JS hides it if the text is not actually clamped (i.e. short enough to fit without truncation). default: '' pcoded {bool} Show a "P-coded" label chip. default: false api_available {bool} Show an "Access via API" text-button, linking to the resource page's #api-access section. Pass for tabular datastore-active resources only. default: false preview_opened {bool} Pre-expand the description on server render (adds `is-open` to both the root element and the description `

`). default: false download_url {string} URL for the primary Download button. default: '#' download_size {string} Human-readable file size (e.g. '14.2K'). Appended to the Download button label when set. default: '' show_download {bool} Render the download button at all. Set False for requestdata resources without access. default: true in_review {bool} Replace the download button with an "Under Review" link. default: false download_extra_classes {string} Extra CSS classes on the download element. Used to attach legacy GA/notification tracking hooks. default: '' download_attrs {dict} Extra HTML attributes on the download element (e.g. data-resource-id, tracking-type). default: {} request_attrs {dict} Extra HTML attributes on the "Request data" element (e.g. data-module click-tracking / onboarding-flow priming). default: {} extra_classes {string} Additional CSS classes on the root element.

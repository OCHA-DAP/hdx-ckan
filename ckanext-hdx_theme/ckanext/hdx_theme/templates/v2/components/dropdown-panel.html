False → multi-select checklist. default: False has_search {bool} Show search input (checklist only). default: False filter_search_key {string} Value for data-filter-search attr. default: '' has_clear {bool} Show clear footer (checklist only). default: False clear_facet {string} Facet key written to data-facet on the clear button.

{# Snippet: config-item.html Path: templates/v2/components/config-item.html Renders a c-config-item — one editable, reorderable item of a sysadmin settings editor: a header with a drag handle, the title (

), optional Move up / down, a collapse toggle and Delete (or a footer Delete), above the caller's fields. Items go in a c-config-item-list (page markup, see the example), whose data attributes drive components/config-item.js (v2-config-item-scripts bundle): drag reordering, Move up / down, collapse, New Item, Delete and Save. With data-config-item-form on the list (form mode) the items are posted by the surrounding page form: no drag reordering, no Save, no AJAX. Parameters ───────────────────────────────────────────────── title {string} Header text, e.g. 'Package Links Item 1'. Required. id {string} Unique id prefix: -heading (title), -body, -delete, -move-up, -move-down. Required. item_id {string} Stored item id (data-config-item-id); empty for an unsaved item. default: '' expanded {bool} Render the body open. default: True draggable {bool} Render the drag handle; False adds c-config-item--static (no grab cursor). default: True title_tag {string} Title element. default: 'h2' collapsible {bool} Render the collapse toggle; False keeps the body open and makes the title focusable (tabindex -1), so Delete can move focus to it. default: True move_buttons {bool} Render "Sort:" with Move up / Move down buttons in the header; config-item.js moves the item, disables the first up / last down and announces the position in the list's [data-config-item-status]. default: False delete_position {string} 'header' | 'footer' (a row after the fields). default: 'header' delete_label {string} Delete button text. default: 'Delete' caller() block The item's fields. ───────────────────────────────────────────────── Example
